      Kurzinfo zu den Optionen

      • Lokal (Ollama) — maximale Datenhoheit, sehr hohe Kosten.
      • API (IONOS) — hoher Datenschutz, geringe Kosten, wenig Modellauswahl.
      • Cloud API (AWS) — viele Open‑Source‑Modelle, sehr hohe Kosten, Datenschutz eingeschränkt.
      • Proprietär (OpenAI / Claude / Gemini) — Premium‑Modelle, amerikanische Anbieter, Datenschutz abhängig, begrenzte Modellauswahl.
